# S2-LASU v1.1 预先记录的补丁口径

日期2026-10-27；R1–R5，不写稿，v1原文件不改动。v1前置哈希快照包含其全部文件；models.py及v1_analysis.py为原代码逐字副本，字段、分类、州名单、FE估计和聚类自由度约定保持一致。

R1：沿用CMS Program Statistics Medicare Part D Enrollment各年官方年龄行；2013–2024均取当年年龄表Total Part D Enrollees、≥65和<65，核查person-year注释，不能拿Medicare全体年龄边际替代。分母是按参保月数折算人年。报告SU、long、glimepiride、glyburide、glipizide每千人年30天量；年龄分子仍以v1可见量为主，并另保留CMS规则界。方向反转比较固定为2013→2024、2019→2024、2020→2024（与v1绝对量表一致）；任一反转在报告开头单列。

R2：CMS的1–10阈值针对claims小计，30天量按每claim 1–12，不能将10当fills上界。设全年龄claims=C、fills=F，对原发小年龄组使用用户要求的宽松0下界，上界U=min(120,F−max(C−10,0))：另一年龄组至少有C−10条claim，每条至少1个fill。*的原发小组为≥65；#为<65，老年组须由已知总量减小组推回。四种主情形为：(1)所有原发小组取0；(2)所有原发小组取U；(3)≥65取其可行下界、<65取互补上界；(4)反向。已知年龄值不变；所有情形保持每行old+young=total，重新计算份额和SU权重。0为有意放宽，不声称原发小计实际可为零；120是依据单claim标准化上限推导的保守界，不是CMS直接公布的fills抑制阈值。

R2判定仅依四种主情形：全部正向且CI不跨0=ROBUST；全部正向但有CI跨0=DIRECTIONAL；任一反向=FRAGILE。精确数值零按保守FRAGILE处理并单列；正向参照v1全国年龄差趋势。完整已发布年龄行103州年子集另外报告，不混入四情形判定。主情形是预设端点情景，不能声称穷尽混合分配；另可报告格份额包络或补充压力分析，但不能改动判定定义。

R3：独立敏感性两项，不叠加。ER/XL加入长效分子，全部SU分母不变；另剔除实际Gnrc_Name含复方成分的所有行，分子分母同步删除。复方按实际核对药名中的斜杠及成分列判定，留完整排除清单。各定义重跑全国年度差和M2，可见量缺失处理与v1一致。

R4：复制核验v1的全期连续样条主指标分段斜率，不擅改为各段独立回归。另给原始端点年龄差变化帮助解释形成阶段，不用后者冒充拟合斜率。

R5：2024全国已发布且受益人数可见的长效药品行集合。并集去重人数下界=max(单行人数)，上界=sum(各行人数)，包含复方行的可能跨行重叠；每行自身已去重，不能把重复处方视为行内重复人。边界只覆盖这些公开药品行；若有整行未公开的长效药物，不声称其为全体长效使用者严格上界。
