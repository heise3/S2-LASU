# S2-LASU 正式分析 v1：冻结口径

日期：2026-10-27；只做A1–A4、表图和判定，不写稿。复用上级目录已验证的2013–2024数据、字段映射和药名清单；旧预检结果不覆盖。

- 主指标：长效30天量/全部SU30天量；长效、短效、其他SU和ER/XL排除规则直接复用 `../code/analyze.py`。组合按含SU分子归类，不重复计量。claims及排除glipizide ER/XL为敏感性。
- 年龄缺失：总量减≥65仅在两项可见时计算；未公开年龄量不填0。汇总observed是可见药品行之和；exact在有抑制时空置。每条被抑制年龄量放宽至[0,全年龄量]，得到保守份额界；界限不覆盖完全未发布的低量药品行。
- A1：全国National行。总体长效、glimepiride系、glyburide系分别除以全部SU。未加权连续线性样条，基函数为1、year−2013、(year−2015)+、(year−2019)+、(year−2023)+；四段连续，各节点没有水平跳跃。段斜率是共同拟合的描述，不是政策因果效应；最后一段仅2023/2024两个年度点。
- A2：只纳入50州。DC、领地、军队、外国、未知等逐年留排除表；全国行用于A1，不能与州行叠加。主面板使用每州年年龄可见SU量>0的份额及该可见量权重，不因个别极低量品牌抑制而整州删除。另给完整已发布年龄行州年子集和抑制分配敏感性。
- A2模型1：百分比份额~old + t + old×t + 州FE；模型2：百分比份额~old + old×t + 州×年FE。后者的共同时间项已被州×年FE吸收。以加权组内消除FE计算；州聚类CR1标准误，保留全设计矩阵秩的有限样本校正G/(G−1)×(N−1)/(N−K)，CI用t(G−1)。另输出不计嵌套FE的校正敏感性，避免隐去自由度约定。
- A2主判定严格依用户规则：M2交互方向与A1全国总体线性年龄差方向一致且95%CI不跨0=PASS；同向但CI跨0=WEAK；反向或数值≈0=KILL倒挂叙事。数值≈0仅指|beta|≤1e−8百分点/年，没有另加事后实质效应阈值。2024州数同时给可见点估计和抑制界下稳健州数。
- 2023描述项：在M2中再加old×I(year≥2023)，保留old×t；后期2023/2024共2年。另用I(year>2023)作只有2024一年敏感性。不解释为Beers更新的因果效应。
- A3：报告2024全国≥65各系GE65_Tot_Benes的药品行合计，并明确跨品牌/药物/组合可能重复，不能当作去重人数。分子内跨品牌重叠同样不可排除。仅有官方2024 ≥65 Part D参保人数才计算每千人指标；不将全Medicare年龄结构乘以Part D总数估算。
- A4主分析：全年龄SU量>0的全部已公开NPI；2019/2024分位数按NPI等权，集中度按长效量排序，以所有合格NPI人数向上取整，量分母为A可回收长效量。专科按SU总量选前10，Endocrinology另列。Spearman只取两年均有SU量的NPI，平均秩处理并列，不补零。
- A4年龄敏感性：至少一条≥65量非缺失且合计>0，计算≥65可见量的份额，表头/分组标出回收率。可见/不可见比较中，“可见”指至少一条≥65量非缺失（含可见合计零）；另标出有数据但量为零NPI。报告所有已发布SU行都可见的子集作为补充。
- A4多层模型：量加权logit变换线性混合模型，z=log((L+c)/(S−L+c))，c=0.5个30天量，另c=0.1/1敏感性；固定效应为实际专科类别，州随机截距。仅50州进入模型，其他地区NPI留排除表。权重w=S/平均S；残差方差sigma²/w，州截距方差tau²，REML拟合。ICC_mean_volume=tau²/(tau²+sigma²)，是平均SU量参照处方者的logit尺度ICC；另报告中位量参照ICC，不能解释为原始份额解释度或病人层面ICC。此模型不把标准化fills当独立二项试验。
- 统计解释：聚类CI是模型推断，不包含抑制不确定性；抑制界另列。全量公开汇总的模型显著性不消除生态/处方者删行偏差。若A2触发KILL，只停止倒挂叙事，其他已授权描述性结果仍交付。

执行补注（2026-10-27，主分析与判定规则不变）：为完整覆盖“只用≥65可见的处方者重复”的两种口径，另加 all_age_GE65_visible_subset：仅保留至少一条≥65值可见的NPI，但仍以全年龄SU计算份额和量权重，分母覆盖率对照全国全年龄SU；与 ge65_visible（实际≥65可见量，且该量>0）同时交付。可见合计为0的NPI纳入前者，不能纳入后者。
